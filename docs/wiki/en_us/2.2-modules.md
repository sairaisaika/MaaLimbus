# 2.2 Module Map

[中文](../zh_cn/2.2-modules.md) · [← Index](index.md) · [← Chapter 2](2-architecture.md)

`src/maalimbus/` holds **93 `.py` files** (including `__init__.py`). Every row below states the responsibility declared by that module's **own docstring on line 1**, so the anchor is written uniformly as `src/maalimbus/<module>.py:1` — open that line to check the module's self-declared job and boundary.

`src/maalimbus/policies.py` is the single exception: it has no module docstring, so its responsibility is declared by the four types it exports and the anchors name those types.

## Table 2.2-2 The vision layer is three kinds of reading, not one

| Kind | Definition | What decides | Representative modules |
| --- | --- | --- | --- |
| Text + normalized position | `src/maalimbus/vision.py:19` `find(records, pattern, roi, size, threshold=.65)` | OCR text hitting a given ROI | `map_vision.py`, `reward_vision.py`, `event_vision.py` |
| Template match | `src/maalimbus/anchors.py:132` `check_template(...)` | a pinned bitmap plus a threshold | `gift_vision.py`, `battle_counter_native.py` |
| Geometry | `src/maalimbus/anchors.py:159` `check_geometry(...)` | normalized ROIs and their size relations | `theme_vision.py`, `star_vision.py` |

The anchor registry lives in `assets/resource/base/anchors.json` (`src/maalimbus/runner.py:226` points `REGISTRY` at it); `anchors.validate()` (`src/maalimbus/anchors.py:31`) checks its shape at load time and `anchors.evaluate()` (`:192`) evaluates anchor by anchor at run time.

## Not verified / open questions

This section states honestly how far this page was verified and what was **not**. The three Mermaid diagrams of chapter 2 are not on this page — they are on the chapter's main page `docs/wiki/en_us/2-architecture.md` (this page measures 0 code fences), so items such as "the diagrams were never rendered by a real renderer" are recorded there and are not repeated here.

1. **Table 2.2-1's "Responsibility" column is each module's self-declaration, not a per-implementation verification.** Line 5 states the rule: every row's responsibility is declared by that module's **own docstring on line 1**. Measured: all 91 `src/maalimbus/<module>.py:1` anchors in the table point at modules that exist, and line 1 really is a docstring (`src/maalimbus/policies.py` excepted, per line 7, whose anchors name its exported types). But this page checked only **that the line exists and is a docstring**; it did not compare all 91 self-declarations against the implementation bodies. Cross-checks exist for a few — for example `src/maalimbus/runner.py:1`'s "the loop, lifted out of `tools/window_step.py`" is supported by `docs/runner.md:3-14` and by the `Device` Protocol at `src/maalimbus/runner.py:251`.
2. **Table 2.2-3 is a timestamped snapshot and drifts.** Its numbers were measured on 2026-10-12 (America/Indianapolis). During writing, `src/maalimbus/runner.py` grew from 3145 to 3216 lines and `src/maalimbus/window.py` from 991 to 1019 — the first draft of this chapter got both wrong. Re-run the measurement before quoting this table; it is not a stable fact.
3. **The two largest modules were not read line by line.** `src/maalimbus/runner.py` (3216 lines) was approached only through `grep`/symbol lookup: its module docstring, the declarations of `Device`/`MaaDevice`/`LocalDevice`/`FakeDevice`/`Observer`/`FrameObserver`/`MaaObserver`/`MirrorRunner`, and a few method headers. `src/maalimbus/mirror_learning_policy.py` (1387 lines) was read only through its module docstring. Their rows in Table 2.2-1 therefore stay at the level of self-declaration.
4. **Not every line anchor was re-verified while adding this section.** Line 120 already declares that every line anchor also names its symbol, to survive drift — and drift did happen: `REGISTRY` in `src/maalimbus/runner.py` moved from `:225` to `:226` (`:225` is now `AUTHORIZATION`), which line 116 now corrects. The remaining `:line` anchors hold **the values read when they were written** and were not all re-run here.
5. **The two languages were not compared sentence by sentence.** Only headings, numbering, tables and paragraph order are guaranteed to correspond; `../zh_cn/2.2-modules.md` is the source and this page is its mirror rather than an independent write, so a factual error in the Chinese page is inherited here.
