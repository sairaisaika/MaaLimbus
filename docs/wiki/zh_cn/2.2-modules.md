# 2.2 模块地图

[English](../en_us/2.2-modules.md) · [← 索引](index.md) · [← 第 2 章](2-architecture.md)

`src/maalimbus/` 共 **95 个 `.py`**（含 `__init__.py`）。下面每一行的职责都由该模块**自己的模块 docstring 在第 1 行**声明，因此锚点统一写作 `src/maalimbus/<模块>.py:1`——打开该行即可核对该模块自我声明的职责与边界。

`src/maalimbus/policies.py` 是唯一的例外：它没有模块 docstring，职责由它导出的四个类型声明，锚点写在具体类型上。

## 本章读到的两处事实校正

这两处是从当前仓库读出来的事实，与其它文档里可能存在的旧描述不一致：

1. `src/maalimbus/runner.py` 实测为 **3216 行 / 192784 字节**（早期记录写的是 2888 行 / 183156 字节，本章初稿写的是 3145 行 / 187332 字节），且仍在变动。
2. `python tools/verify_pipeline_spec.py` 输出 `ok — 0 problem(s)`（`docs/maaframework-conformance.md:132`），因此 `agent/main.py:48-69` 的 16 个注册名与 `assets/resource/base/pipeline/mirror.json` 里引用它们的节点是**一一对得上**的；唯一例外是刻意保留的 33 个不可达节点，它们被报告为提示而不是失败（`docs/maaframework-conformance.md:141-142`）。

## 未验收 / 待核实

本节如实列出这一页核实到哪里、还有什么**没有**核实。第 2 章的三张 Mermaid 图不在本页，而在第 2 章主页 `docs/wiki/zh_cn/2-architecture.md`（本页不含任何围栏块），因此「图未经真实渲染器验证」这类未验收项记在那里，这里不重复。

1. **表 2.2-1 的「职责」列是模块的自我声明，不是逐实现核验。** L5 声明的口径是「每行职责由该模块自己的第 1 行 docstring 声明」。实测表内 91 个 `src/maalimbus/<模块>.py:1` 锚点全部指向存在的模块，且第 1 行确实是一句 docstring（`src/maalimbus/policies.py` 按 L7 的说明除外，其锚点写在具体类型上）。但本页**只核了「这一行存在且是一句 docstring」**，没有把 91 条自我声明逐条与实现体对照。做了交叉验证的是少数，例如 `src/maalimbus/runner.py:1` 的「把循环从 `tools/window_step.py` 提升为库」有 `docs/runner.md:3-14` 与 `src/maalimbus/runner.py:251` 的 `Device` Protocol 支持。
2. **表 2.2-3 是带时点的实测快照，会漂。** 表中数字实测于 2026-10-12（America/Indianapolis）。写作期间 `src/maalimbus/runner.py` 就从 3145 行涨到 3216 行、`src/maalimbus/window.py` 从 991 行涨到 1019 行——这两个数字本章初稿就写错过一次。该表每次引用前都必须重跑测量，不能当稳定事实。
3. **两个大模块没有被逐行读完。** `src/maalimbus/runner.py`（3216 行）只按 `grep`/符号定位读了模块 docstring、`Device`/`MaaDevice`/`LocalDevice`/`FakeDevice`/`Observer`/`FrameObserver`/`MaaObserver` 与 `MirrorRunner` 的声明及少量方法头部；`src/maalimbus/mirror_learning_policy.py`（1387 行）只读了模块 docstring。表 2.2-1 里这两个模块的「职责」因此停留在自我声明层面。
4. **行号锚点没有在本次补写时全部复验。** L120 已声明「行号锚点一律同时写出符号名以抗漂移」，漂移也确实发生了：`src/maalimbus/runner.py` 的 `REGISTRY` 已从 `:225` 移到 `:226`（`:225` 现在是 `AUTHORIZATION`），本节据此更正了 L116。其余 `:行号` 锚点是**写入时读到的值**，除本次实测到的那一处外未逐个重跑核对。
