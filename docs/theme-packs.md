# 主题包选择

开发任务「Select theme pack」只用于当前已打开的困难主题包选择页。
它不会自行入场，尚未接通镜牢地图和五层循环。

选择保存队伍编号后，可以在任务选项中选一个主题包和权重，将偏好保存到该队伍。
选择「Keep saved preferences」沿用已有设置；不填写名称。权重越大越优先，0 表示禁止选择。
目录中的 95 个名称来自固定版本 Lix，未配置的已识别名称使用中性权重 10。
上游旧权重仅保留来源，不当作当前赛季最佳攻略。日语标题本地化识别还需要实际画面。

流程为：权限/单控制器检查 → 读取队伍 → 保存偏好 → 检查资源与失败界面 →
确认 HARD → 排序候选 → 一次 Maa Swipe → 保存新截图 → 停在待验收的地图边界。
选中、下一地图和通关均不会因为拖动成功而自动记为完成。

## 识别依据

参考 Lix `431b432e22f0b0da08b95d7c478fa213be20b3e8`：

- `lalc_backend/utils/get_save_theme_packs.py`：固定详情图标中心对应卡片
  `[cx-135, cy-35, 170, 330]`，参考分辨率 1280×720。仅 OCR 卡片底部标题。
- `lalc_backend/task_action/mirror.py` 的 `mirror_select_theme_pack`：向下拖动卡片，
  按配置权重选择。这里改为卡片内部避开详情按钮的起点，400px 向下拖动。
- `theme-catalog.json` 记录五个固定小图标的 SHA256、源路径和版本。
  不导入或匹配主题包的整张卡面。

图标在限定区域按画面宽度缩放，HARD/NORMAL 与刷新图标必须唯一、详情图标最多六个。
标题只关联自己的卡片；允许 Maa 检测框向外扩出参考分辨率下 8px，跨卡片仍拒绝。
NEW 包不猜名称；低置信度、重复名称、重叠卡片和未知标题均不能成为拖动目标。
不点击刷新按钮，也不沿用 Lix 无匹配时随机选择的回退。

PI 的队伍编号、包名和权重写入不同配置节点，避免覆盖整个 `custom_action_param`
时丢失另一个选项。队伍编号/自定义名称也已拆分。偏好仍使用原有原子保存及旧配置兼容。

## 已验证范围

```powershell
python tools/verify_theme_replay.py --binary <Maa原生库目录>
```

七个派生回放经真实 Maa OCR/生产 Pipeline 验证：保存偏好、变化卡面、NEW 排除、
未知名字、NORMAL、资源弹窗、全部禁选。允许情况仅有一次原生 Swipe，停止情况零输入。
拖动后保存新的观察记录；始终保留 `selected: false`、`verified_clear: false`。
这是离线派生素材验证，尚无实机选包、日语标题或地图转场成功证据。
